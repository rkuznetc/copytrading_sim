# Симулятор копитрейдинга

## Итерация 2: сравнения и графики

Добавлены подключаемые политики, пошаговый интерфейс среды и централизованная
логистическая матричная факторизация. Старый запуск генерации работает без изменений.

```bash
python -m copytrading_sim.experiments --config configs/experiments/quick.yaml --run-id iter2-quick
```

Результат: `artifacts/experiments/iter2-quick/report.html`, `report.md`, семь
PNG/SVG-графиков, числовые таблицы, исходный набор данных и контрольная точка модели.
Для трёх независимых миров: `configs/experiments/standard.yaml`.

[Полный протокол, интеграция модели и ограничения](docs/iteration_02.md).
Эксперимент разделяет совместимость рекомендаций, предсказание выбора и отклики на
новые показы. Федеративное обучение и автоматический замкнутый цикл пока не реализованы.


Исследовательский Python-проект для магистерской работы о персонализированных
федеративных рекомендациях стратегий. Сейчас реализован **генератор фиксированных
пользовательских историй**, а не обученная рекомендательная система.

## Итерация 1: воспроизводимый запуск

Конвейер создаёт пользователей и стратегии, рассчитывает совместимость, формирует
показы и моделирует выбор копирования. Теперь результат сохраняется отдельным
запуском, проверяется и загружается без повторной генерации.

**Формулы совместимости, архетипы и модель отклика не менялись.** Изменена организация
случайности: одинаковый `seed` уже не воспроизводит таблицы старого прототипа.
В новой версии повторение того же запуска при том же коде и окружении воспроизводит
таблицы. Между разными версиями Python/NumPy/Pandas побитовое совпадение не обещается.

## Установка и проверки

Из корня репозитория:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[dev]"
python -m pytest -q
```

## Запуск

```bash
python -m copytrading_sim.main --config configs/small.yaml --run-id smoke-001
```

Результат: `artifacts/datasets/small_run/smoke-001/`. Повторный запуск с тем же именем
завершится ошибкой **без перезаписи**. Без `--run-id` создаётся уникальное имя:

```bash
python -m copytrading_sim.main --config configs/small.yaml
```

Для другого каталога или просмотра первых строк:

```bash
python -m copytrading_sim.main --config configs/small.yaml \
  --output-dir artifacts/runs --run-id demo-001 --preview 2
```

Каталоги из конфигурации и относительные пути CLI разрешаются относительно корня
проекта; абсолютные пути также поддерживаются. Это рассчитано на работу из исходного
репозитория с установкой `pip install -e .`, а не на развёртывание отдельного wheel.

## Конфигурация

`base.yaml` и `small.yaml` по-прежнему подходят. Дополнительные настройки
совместимости, показа и выбора получают значения по умолчанию из кода и сохраняются
в `config.resolved.yaml`.

Файлы в `configs/` **не объединяются автоматически**. Для фрагмента настроек:

```bash
python -m copytrading_sim.main --config configs/small.yaml \
  --override configs/logging_policy.yaml --run-id policy-001
```

`--override` можно повторить; более поздний файл переопределяет предыдущий.
`logging_policy.yaml` исправлен под реально используемую секцию `exposure_policy`.
Прежняя секция `logging_policy` кодом не читалась. Поле `policy_name` — подпись в
логах, а **не переключатель алгоритма**: сейчас доступна только смешанная политика.

`validation.yaml` пока является заготовкой будущего этапа. Не передавайте его через
`--override`: структурные проверки текущей итерации обязательны и не отключаются.
Неизвестные ключи, нулевые размеры выборки, отрицательные веса, `NaN` и бесконечные
параметры отклоняются, а не игнорируются.

## Что сохраняется

```text
smoke-001/
|-- config.resolved.yaml       # фактически использованная конфигурация
|-- manifest.json             # схемы, SHA-256, код, окружение, потоки случайности
|-- summary.json              # размеры таблиц и описательная статистика
|-- validation.json           # результат структурных проверок
|-- requirements.runtime.txt  # версии основных runtime-библиотек
|-- tables/
    |-- users.csv
    |-- strategies.csv
    |-- compatibility.csv
    |-- exposures.csv
    |-- copy_decisions.csv
    |-- copy_events.csv
    |-- metadata.csv
```

`manifest.json` записывается последним. Папка без него не считается завершённым
запуском. При ошибке записи созданная папка удаляется; ранее существовавшие запуски
не затрагиваются. При жёстком завершении процесса может остаться незавершённая папка.

`summary.json` различает **долю списков с копированием** и **долю показанных строк с
копированием**. При размере списка 5 это разные показатели: на один список возможно
не более одного выбора. Статистика не является оценкой качества рекомендаций.

## Загрузка в Python

```python
from copytrading_sim.datasets.exporters import load_run

run = load_run("artifacts/datasets/small_run/smoke-001")
users = run.tables["users"]
interactions = run.tables["copy_decisions"]
print(run.summary)
print(run.manifest["source"])
```

`load_run` проверяет контрольные суммы, восстанавливает типы колонок, сверяет
размеры и структурные инварианты. Применяется обычное чтение CSV, без pickle.
Путь загрузки задаётся относительно текущего рабочего каталога, либо абсолютно.

Программный запуск без файлов остаётся доступным:

```python
from copytrading_sim.config import load_config
from copytrading_sim.simulator.pipeline import run_pipeline
from copytrading_sim.datasets.exporters import save_run

config = load_config("configs/small.yaml")
tables = run_pipeline(config)
run_dir = save_run(tables, config, run_id="python-001")
```

`run_pipeline` не пишет на диск. `save_run` не генерирует данные повторно.
Старый параметр `rng` у `run_pipeline` сохранён: из переданного генератора берётся
одно число для корневого seed; фактический seed записывается в метаданные и при
экспорте — в конфигурацию. Предпочтительный способ управления запуском — `random.seed`.

## Что проверяется

Уникальность и связи идентификаторов; размеры таблиц и списков показа; допустимые
диапазоны и конечность чисел; отсутствие повторов стратегии внутри списка; не более
одного копирования; согласованность таблиц показов, решений и событий; сумма
вероятностей выбора вместе с одним вариантом отказа; корректность метаданных.

Проверки **не доказывают реалистичность финансовых данных или качество рекомендателя**.
Случайные и популярные модели сравнения, обучение и федеративный цикл ещё не добавлены.

## Ограничения и следующие изменения

Числовые признаки стратегий пока синтетические; временные ряды и финансовые результаты
копирования не моделируются. В таблицах присутствуют диагностические величины
(`compatibility_score`, вероятности отклика, архетипы генератора): их нельзя бездумно
передавать обучаемой модели. Разделение доступа будет частью следующей итерации.
